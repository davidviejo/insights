03 · Cómo investigarlo

Hipótesis principal

La propuesta se está escribiendo desde una sola keyword o forzando una longitud objetivo, perdiendo cobertura semántica o diferenciación.

Evidencia / causas

  • impressions
  • clicks
  • ctr
  • position

No asumir

['No conviertas “truncado” en “malo”. Antes de acortar, comprueba qué conceptos aportan intención y cuáles son ruido.', 'No convertir la description en un listado de keywords.', 'No inventar propuesta de valor, atributos ni datos que la landing no sostenga.']

Alternativas

  • Google no usa la description declarada y el problema está en el contenido
  • duplicidad de plantilla y no de redacción
  • el CTR bajo se explica por la SERP y no por el snippet
04 · Plan de acción
1
Confirmar alcanceLa propuesta se prioriza por indexabilidad y rendimiento; no se invierte trabajo de snippet en URLs no indexables.
2
ImplementarRedactar una description específica por landing, manteniendo primero los conceptos obligatorios y condensando después redundancias o claims prescindibles.
3
Decisión PLAUDImplementar solo en URLs que deben posicionar; tags se resuelven primero en TPL-100.
05 · Criterio de cierre

QA técnico

La description propuesta representa la landing, no duplica otras URLs y conserva los conceptos relevantes antes de cualquier posible truncamiento. · Compare before/after using the same segment and measurement definition. · Document implementation date, sources and affected sample.
