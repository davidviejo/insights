03 · Cómo investigarlo

Hipótesis principal

El marcado se ha ido añadiendo por plugin o por página concreta, sin una definición previa de tipo y propiedades por tipología.

Evidencia / causas

  • required_properties
  • missing_properties
  • implementation_method
  • validation_result

No asumir

['No marcar contenido que no es visible en la página.', 'No añadir un tipo de schema por el que la página no es elegible.', 'No planificar sobre una URL suelta: el plan se define por tipología y se implementa en plantilla.']

Alternativas

  • el marcado existe pero se inyecta por JavaScript y no se ve en el HTML inicial
  • la tipología no es elegible para ningún rich result
  • el plugin ya cubre el tipo y falta solo una propiedad
